# История Средних веков — тренажёр

Тренажёр по школьному учебнику истории Средних веков (V–XV вв.): термины и даты.

**Открыть:** https://fastest13.github.io/medieval-history/

## Режимы

1. **Соедини термины с определениями** — 10 терминов, определения нужно поставить напротив.
2. **Выбери определение** — термин и 5 похожих по смыслу определений, 20 вопросов.
3. **Расставь события по порядку** — 10 событий без дат, выстроить хронологию перетаскиванием.
4. **Что произошло в этот год?** — дата и 5 близких по времени событий, 20 вопросов.

В конце каждого режима — оценка от рыцаря, разбор ошибок и кнопка «Поделиться».

## Запуск

Сборка не нужна: чистые HTML, CSS и JavaScript без библиотек. Достаточно открыть `index.html` в браузере.

Данные (термины и события) — в `js/data.js`.
